# Session Log: 2026-09-02 (Session 5)

## Objective
Fix the deprecation warnings in the Android build system for Gradle, Android Gradle Plugin (AGP), and Kotlin, migrating the project to the modern built-in Kotlin and AGP 9+ standard.

## Findings & Decisions
- Upgraded Gradle distribution to **Gradle 9.5.1** in `gradle-wrapper.properties` to satisfy AGP 9.3+ requirements.
- Upgraded Android Gradle Plugin to **AGP 9.3.0** in `settings.gradle.kts`.
- Upgraded Firebase Plugins (`google-services` to `4.5.0`, `firebase-perf` to `2.0.2`, `firebase-crashlytics` to `3.0.8`) to ensure full compatibility with modern Gradle.
- Migrated to **Built-in Kotlin**:
  - Removed explicit application of the Kotlin Gradle Plugin (`id("org.jetbrains.kotlin.android")`) in `android/app/build.gradle.kts`.
  - Added `android.builtInKotlin=true` to `android/gradle.properties`.
  - Defined Kotlin Gradle Plugin in the `plugins` block of `android/settings.gradle.kts` with `apply false` specifying version `2.3.20` to satisfy Flutter's validation checks, while allowing the built-in system to build correctly.
- Addressed AGP 9+ `ApplicationExtensionImpl` class cast issue with the legacy Flutter Gradle Plugin by setting `android.newDsl=false` in `gradle.properties` (as recommended by the Flutter tool itself).
- Enabled build features `resValues` (`resValues = true`) in `android/app/build.gradle.kts` because AGP 9+ disables it by default when building flavors with custom resource values.
