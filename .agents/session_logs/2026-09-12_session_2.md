- **Bug Fix: 60-Month Schedule Collapsible Crash**:
  - *Root Cause*:
    1. In `RDInstallmentTile`, `titleRow` was a horizontal `Row` containing Month number, Status Badge, and Late Fee Badge. When expanded inside `_RDYearlyScheduleAccordion`, the available width (335px) was exceeded by 42px on narrow viewports/cards, triggering `A RenderFlex overflowed by 42 pixels on the right` at `rd_installments_section.dart:708:22`.
    2. When Flutter reported this rendering overflow to `FlutterError.onError`, `lib/main.dart` sent it to `FirebaseCrashlytics`. Because Crashlytics is unsupported on Flutter Web, an assertion failed in the Firebase SDK (`pluginConstants['isCrashlyticsCollectionEnabled'] != null`), throwing an uncaught JS/Dart error that halted the application runtime.
  - *Fix*:
    1. Converted `titleRow` in `RDInstallmentTile` from a rigid `Row` to a responsive `Wrap` with `WrapCrossAlignment.center` so tags wrap gracefully without layout overflow.
    2. Wrapped trailing text rows in `subtitleColumn` (`openingBaseline`, `depositedToPo`, `pendingPoDeposit`) with `Expanded`.
    3. Added `PageStorageKey` to accordion expansion tiles in `_RDYearlyScheduleAccordion` and `_buildYearSection` to stabilize state across rebuilds.
    4. Guarded `FirebaseCrashlytics` error handlers in `lib/main.dart` with `if (!kIsWeb)`.
