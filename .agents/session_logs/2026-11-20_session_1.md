## 1. Design Decisions (Confirmed with Owner)
- **Mechanism**: Stay signed in as the admin (`auth.uid()` = admin). Pass an explicit `effectiveAgentId` into repositories and backwards-compatible `p_agent_id UUID DEFAULT NULL` into all 6 write RPCs. Authorization in Postgres flows through `private.can_access_agent(target_id, mode)` so user-consented support grants or portfolio sharing can plug in later without rewriting repositories or RPCs.
- **Full CRUD by Default (Option C)**: Owner chose full CRUD immediately upon switching (no read-only lock toggle and zero `isReadOnly` branching in feature screens), keeping the admin experience 1:1 with the real agent UI while minimizing diff footprint (26 files).
- **Root-Level Banner**: Mounted topology-invariant `_ActingAsShellFrame` + `ActingAsBanner` inside `MaterialApp.router.builder` so the red warning banner stays pinned across tabs and pushed detail/form routes without unmounting `GoRouter` or double-padding `LocalBackendBanner` / `DemoBanner` below.
- **Audit Trail**: Append-only `public.admin_audit_logs` recording UI session events (`start`, `end`) and automatic server-side per-RPC mutations (`rpc:*`) whenever `v_agent_id <> auth.uid()`.
- **Trigger Placement**: Admin-only `Switch Account` `IconButton` in `DashboardScreen` app bar (mobile) and `MainShellScaffold` Navigation Rail (tablet/desktop), hidden for non-admins and in Demo Mode.
