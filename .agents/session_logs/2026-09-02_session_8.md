# Session Log: 2026-09-02 (Session 8)

## Objective
Implement P2 Optimization: Filter Real-Time CDC Streams by Agent ID.

## Findings & Decisions
- Real-time CDC (Change Data Capture) streams previously listened to all changes to the underlying tables (`customers` and `account_identities`) database-wide, filtering them client-side. This could cause heavy network and client-side message processing overhead on shared tables if multiple agents were active.
- Added `.eq('agent_id', _userId)` directly onto the PostgREST stream builders:
  - In `watchCustomers()` within `SupabaseCustomerRepository`.
  - In `watchOneTimeDeposits()` within `SupabaseOneTimeDepositRepository`.
  - In `watchRecurringDeposits()` within `SupabaseRecurringDepositRepository`.
- This restricts real-time updates pushed from Supabase to only include records matching the current authenticated agent's ID, preserving network egress and minimizing client processing overhead.
