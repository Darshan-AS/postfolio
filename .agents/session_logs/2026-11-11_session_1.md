## Alignment Decisions Locked
- **Connectivity & Scale**: Single agency (1–2 devices) with reliable mobile data — keep online-first Supabase + fast in-memory caching (skip `Drift`/offline outbox).
- **Cloud / Firebase**: Excise Firestore & Firebase Auth in Stage 2; retain **Firebase Hosting** (IAM already resolved in `v2.3.1+22`) + **Firebase Crashlytics on Android**.
- **Backups**: Nightly GitHub Action (`pg_dump -Fc` + `age` encryption) uploaded to **Google Drive** in Stage 1 via **`rclone` OAuth2 refresh token (`drive.file` scope)** (avoids GCP Service Account 0-byte Drive quota restriction on personal `@gmail.com` accounts and stays backend-agnostic).
- **Refactoring Depth**: **Option A (Pragmatic High-ROI)** locked for Stages 3–4 (`Paise`/`LocalDate` Dart extension types + single-transaction atomic fact+summary RPCs + `ON DELETE RESTRICT`), combined with **DDD × Pragmatic TDD** across all stages.
- **DOP Fee Rule**: Keep current calendar-month `RDLedgerRules.defaultedMonths` rule; allow overriding actual fee charged at counter (`feePaid`) in Stage 4.
- **PII / Security**: Plaintext under Supabase RLS is sufficient for personal agency use — lock down exposed RPCs/grants and remove `data/` asset bundling.
- **Scope**: Defer net-new product features (Commissions/TDS, Household Split, Persisted C-number Lots, Today's Desk) until after Stages 0–5 stabilization and cleanup.
