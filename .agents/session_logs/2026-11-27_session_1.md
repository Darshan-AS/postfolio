## Objective
Replace Postfolio's raw Demo Mode Play Store screenshots with an automated, industry-standard Flutter marketing screenshot pipeline (`tool/store_screenshots/`) that generates framed, captioned, opaque 24-bit RGB PNGs directly from the real M3 Expressive UI.

## Changes Made

2. **`tool/store_screenshots/marketing_frame.dart`**: Built `PortraitMarketingSlide` (`360×640` logical @ 3× = `1080×1920`), `LandscapeMarketingSlide` (`640×360` logical @ 3× = `1920×1080`), `PixelDeviceFrame` (hardware bezel, drop shadows, `9:41` Android status bar, bottom gesture indicator), and `SlideBackdropStyle` (`royalBlue`, `softIce`, `midnight`) matching `docs/store_assets/feature_graphic_1024x500.png`.
3. **`tool/store_screenshots/opaque_png.dart`**: Added pure-Dart `writeOpaqueRgbPng` (`colorType = 2`, 24-bit RGB PNG with no alpha channel) so generated assets comply with Play Console's no-transparency rule.
