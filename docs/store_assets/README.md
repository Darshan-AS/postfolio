## 🔄 Regenerating After UI Changes
Whenever screens or copy change, regenerate every store slide + feature graphic directly from `FakeDataSource.forDate` (no Demo Mode banner, no emulator required):

```bash
flutter test tool/store_screenshots/generate_store_screenshots_test.dart --update-goldens
```

Or run the VS Code task **`Store: regenerate Play Store screenshots`**.

Source files:
- [`tool/store_screenshots/generate_store_screenshots_test.dart`](../../tool/store_screenshots/generate_store_screenshots_test.dart) — slide definitions & deterministic fixture overrides
- [`tool/store_screenshots/marketing_frame.dart`](../../tool/store_screenshots/marketing_frame.dart) — continuous wave backdrop, headlines, extruded 3D Pixel 11 Pro / Pixel Tablet bezels, and `FeatureGraphicBanner`
- [`tool/store_screenshots/screenshot_fonts.dart`](../../tool/store_screenshots/screenshot_fonts.dart) — bundled `Roboto` v3.016 (`tool/store_screenshots/fonts/`) + SDK `MaterialIcons` loader
- [`tool/store_screenshots/opaque_png.dart`](../../tool/store_screenshots/opaque_png.dart) — 24-bit opaque RGB PNG encoder & panoramic horizontal slicer (Play Console compliant)
